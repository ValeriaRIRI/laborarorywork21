# Laboratorywork21
## База данных сотрудников
Консольное приложение для создания хранения и управления информацией о игроках различных клубов.
**Назначение**

 Проект демонстрирует работу с структурами данных, файловым вводом-выводом, алгоритмами поиска и сортировки в языке C  

**Ключевые алгоритмы**:  
  `Поиск`: Линейный поиск по фамилии search_surname()  
  `Сортировка`: Быстрая сортировка qsort() по количеству игр  
  `Вычисление возраста`: Корректный расчет возраста с учетом дня рождения  
  `Фильтрация`: Выборка молодых защитников с записью в файл

## 📋 **Функциональные возможности**

### **Основной функционал:**

- ✅ **CRUD-операции:** Создание, чтение, обновление

- ✅ **Поиск:** По фамилии, просмотр, обновление данных

- ✅ **Сортировка:** По количеству игр

- ✅ **Сохранение:** Запись в текстовый файл для долговременного хранения

- ✅ **Консольный интерфейс:** Интерактивное меню с 8 командами

🔧 Реализованные функции
1. ## int print_menu(void)
 - **Назначение**: Вывод меню программы на экран
  - **Параметры**: нет  
- **Возвращает**: 0

2. ## int writeYoungDefendersToFile(football_t *players, int size, int current_year, int current_month, int current_day, int* count)
- **Назначение**: Запись молодых защитников (до 20 лет, ≥40 игр) в файл young_defenders.txt
- **Параметры**:
    - `players` - массив игроков
    - `size` - размер массива
    - `current_year/month/day` - текущая дата
    - `count` - указатель на счетчик записанных игроков
- **Возвращает**: 0 при успехе, -1 при ошибке файла

3. ## int age(int year, int month, int day, int cur_year, int cur_month, int cur_day)
- **Назначение**: Вычисление возраста человека на текущую дату
- **Параметры**:
    - `year/month/day` - дата рождения
    - `cur_year/month/day` - текущая дата
- **Возвращает**: возраст в годах

4. ## int fill_array(football_t* players, int size)
- **Назначение**: Инициализация массива игроков тестовыми данными
- **Параметры**:
    - `players` - массив игроков
    - `size` - размер массива
- **Возвращает**: 0
 
5. ## int print_array(football_t* players, int size)
- **Назначение**: Табличный вывод массива игроков
- **Параметры**:

  - `size` - размер массива

6. ## int print_player(football_t player)
- **Назначение**: Вывод одной записи игрока в табличном формате
- **Параметры**:
  - `player` - структура игрока
- **Возвращает**: 0

7. ## int change_record(football_t* players, int size)
- **Назначение**: Поиск и редактирование записи по фамилии
- **Параметры**:
    - `players` - массив игроков
    - `size` - размер массива
- **Возвращает**: 0 при успехе, -1 если не найдено

8. ## int edit_player(football_t* player)
- **Назначение**: Редактирование полей структуры игрока

9. ## football_t* search_surname(football_t* players, int size, const char* surname)
- **Назначение**: Линейный поиск игрока по фамилии
- **Параметры**:
    - `players` - массив игроков
    - `size` - размер массива
    - `surname` - искомая фамилия
- **Возвращает**: указатель на найденного игрока или NULL

10. ## int compare_games(const void* a, const void* b)
- **Назначение**: Компаратор для qsort по количеству игр
- **Параметры**:
    - `a, b` - указатели на элементы для сравнения
- **Возвращает**: отрицательное/нулевое/положительное значение

11. ## int sort_by_games(football_t* players, int size)
- **Назначение**: Сортировка массива по количеству игр + вывод
- **Параметры**:
    - `players` - массив игроков
    - `size` - размер массива
- **Возвращает**: 0

12. ## int input_file(const char* filename, football_t* arr)
- **Назначение**: Загрузка данных игроков из файла
- **Параметры**:
    - `filename` - имя файла
    - `arr` - массив для загрузки
- **Возвращает**: количество загруженных записей

  - `filename` - имя файла
